**🎯 Purpose**



This module provides a user-friendly interface to interact with the RAG system and evaluates the quality, relevance, and performance of the generated answers.



**📥 Input**



💬 User Questions / Queries

📚 Retrieved Documents / Context

🤖 Generated Answers

📊 Evaluation Results



**🔄 Basic Flow**



💬 User Query

↓

🖥️ User Interface

↓

🔍 RAG System

↓

📚 Retrieved Context + 🤖 Generated Answer

↓

📊 Evaluation

↓

📤 Display Result



**⚙️ Working**



💬 Accept the user's question through the UI.

🔍 Send the query to the RAG pipeline for processing.

📚 Receive the relevant retrieved documents and context.

🤖 Display the answer generated by the LLM.

📊 Evaluate the response based on relevance, correctness, faithfulness, and retrieval quality.

📈 Display the evaluation results and performance metrics through the UI.



**📤 Output**



🖥️ Interactive RAG User Interface

💡 Generated Answer

📚 Retrieved Sources

📊 Evaluation Scores \& Performance Metrics
